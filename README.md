# 伊莫家园生产计算器

《伊莫》家园生产规划工具：填好你的条件，点一下"计算最优方案"，就得到产值最高的种植与生产安排。全部计算在你的浏览器里完成，数据只保存在你自己的设备上。

## 快速上手

1. 顶部设置**当前等级**（默认 10 级，清空＝不限）、**时长**、**工作系数**；
2. 在"规划配置"里按需填写（都可留空）：
   - **数据管理**：改各建筑的拥有数量，改完约 1 秒自动重算；
   - **工作效率**：给单个建筑设独立效率%，不填的跟随全局系数；
   - **存量资源**：填你已有的资源数量，会当作可用原料参与规划；
   - **自定义生产**：指定某建筑保底生产某产物，同一建筑可加多行（如 1 块月露萝卜＋1 块盈月椒，其余地块自动最优）；
3. 点**计算最优方案**，查看结果。

## 结果怎么看

- **概览卡片**：最优总产值、整数可行方案、出售种类、每小时净利润；
- **种植与生产安排**：田地和林地有**逐块时间轴**——每一块地种什么、种多久、第几小时换茬一目了然；其他建筑显示占比条与"X块×Y轮·时长"的整数安排；
- **图表**：出售价值构成、各产物净利润、净收益排行（悬停可看材料明细）；
- **方案明细**：每个建筑每个产物的轮次与占用；展开可看物料平衡（产出/消耗/每小时速率/消耗去向）与未参与的配方及原因。

## 两个开关

- **赛季配方**：默认不勾选＝不使用赛季作物（获取渠道有限）；勾选后参与自由规划。无论是否勾选，你在"自定义生产"里设定的赛季产物都会按设定数量精确参与，其衍生加工（如月露萝卜花、烤盈月椒）也会自动安排；
- **懒人模式**：原料类建筑（田地/林地等）每块地全程只种一种产物，省心不换茬。可搭配：
  - **原料配方**：限制每种建筑最多用几种产物（1＝整齐划一；自定义生产不占额度）；
  - **换配方**：允许全程统一切换 1~2 次配方（所有原料建筑同时换）。

## 其他说明

- **加工链**：木块/矿砂等材料会自动连同林地/矿山的副产物一起，加工到当前等级能做的最高层级（层压木梁、致密木构件、微晶矿板等）；
- **时间口径**：工作量型建筑每轮时间＝工作量÷工作系数（水井/矿山/采蜜鸟屋等直接产出型再÷1.25）；生长型按生长时间；
- **收益口径**：净利润只计实际卖出的盈余，自用材料不计；材料成本按售价折算；
- **数据保存在哪**：全部在本机浏览器（localStorage），换设备或清浏览器数据不会同步；想重置就清除站点数据或逐项删除；
- **手机可用**：页面自适应手机屏幕。

## 常见问题

- **改了建筑数量没反应？** 会自动重算，稍等 1 秒即可；
- **提示"自定义生产不可用"？** 该产物当前等级不够或材料无来源，看提示里的原因；
- **提示与"整齐划一"冲突？** 同一建筑的自定义产物数超过了"原料配方"限制（自定义不占额度，但自由部分仍受限），放宽限制或减少自定义项。
