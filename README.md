伊莫家園生產計算器
《伊莫》家園生產規劃工具：填好你的條件，點一下「計算最優方案」，就得到產值最高的種植與生產安排。全部計算在你的瀏覽器裡完成，資料只保存在你自己的裝置上。

快速上手
在「生產計算」頁頂部的條件欄設定當前等級（預設 10 級，清空＝不限）、時長、工作係數；

在「規劃配置」裡按需填寫（都可留空）：

資料管理：改各建築的擁有數量，改完約 1 秒自動重算；

工作效率：給單個建築設獨立效率%，不填的跟隨全局係數；

存量資源：填你已有的資源數量，會當作可用原料參與規劃；

自訂生產：指定某建築保底生產某產物，同一建築可加多行（如 1 塊月露蘿蔔＋1 塊盈月椒，其餘地塊自動最優）；

點計算最優方案，查看結果。

結果怎麼看
概覽卡片：最優總產值、整數可行方案、出售種類、每小時淨利潤；

種植與生產安排：田地和林地有逐塊時間軸——每一塊地種什麼、種多久、第幾小時換茬一目了然；其他建築顯示佔比條與「X塊×Y輪·時長」的整數安排；

圖表：出售價值構成、各產物淨利潤、淨收益排行（懸停可看材料明細）；

方案明細：每個建築每個產物的輪次與佔用；展開可看物料平衡（產出/消耗/每小時速率/消耗去向）與未參與的配方及原因。

兩個開關
賽季配方：預設不勾選＝不使用賽季作物（獲取渠道有限）；勾選後參與自由規劃。無論是否勾選，你在「自訂生產」裡設定的賽季產物都會按設定數量精確參與，其衍生加工（如月露蘿蔔花、烤盈月椒）也會自動安排；

懶人模式：原料類建築（田地/林地等）每塊地全程只種一種產物，省心不換茬。可搭配：

原料配方：限制每種建築最多用幾種產物（1＝整齊劃一；自訂生產不佔額度）；

換配方：允許全程統一切換 1~2 次配方（所有原料建築同時換）。

能力圖鑑
頁面頂部的「能力圖鑑」頁籤用來挑選合適的伊莫去建築上崗（資料來自官方 wiki 圖鑑，208 個形態）：

建築崗位推薦：每個建築偏好的條件——圓形徽章是推薦性格（後天養成屬性，僅供參考），後半段是先天條件（屬性/能力/家族）。點擊卡片自動按該條件篩出合適的伊莫；田地和林地無需推薦不顯示，還沒錄入條件的建築（如星落吊床、花舞風車）顯示「資料待補充」；

伊莫篩選：能力類型（火/草/水/土/電/冰/風/暗/光/搬運/手工/遊玩/製香，可多選＝須同時具備）、能力等級（全部 / Lv2+ / Lv3+ / Lv4+）、名稱或編號搜尋（如「蓬蓬羊」或「018」）。

其他說明
加工鏈：木塊/礦砂等材料會自動連同林地/礦山的副產物一起，加工到當前等級能做的最高層級（層壓木梁、緻密木構件、微晶礦板等）；

時間口徑：工作量型建築每輪時間＝工作量÷工作係數；生長型按生長時間；

收益口徑：淨利潤只計實際賣出的盈餘，自用材料不計；材料成本按售價折算；種植類每輪扣一粒種子價；

資料保存在哪：全部在本機瀏覽器（localStorage），換裝置或清瀏覽器資料不會同步；想重置就清除站點資料或逐項刪除；

手機可用：頁面自適應手機螢幕。

常見問題
改了建築數量沒反應？ 會自動重算，稍等 1 秒即可；

提示「自訂生產不可用」？ 該產物當前等級不夠或材料無來源，看提示裡的原因；

提示與「整齊劃一」衝突？ 同一建築的自訂產物數超過了「原料配方」限制（自訂不佔額度，但自由部分仍受限），放寬限制或減少自訂項。
